# 팀 초대

사이드바 → **팀 멤버** (`/settings/members`)

1. 이메일 입력 + 권한 선택(`member` / `admin` / `guest`) → **초대**
2. 상대에게 메일이 간다 (대시보드에 설정한 **Gmail SMTP** 로 나간다)
3. 링크를 누르면 로그인 후 수락 화면이 뜨고, **참여하기** 를 누르면 멤버가 된다

## 설계 결정

**`service_role` 키를 쓰지 않는다.**
Supabase 의 `inviteUserByEmail` 은 관리자 API 라 service_role 키가 필요한데,
anon 키의 `signInWithOtp` 로도 같은 SMTP 를 타고 메일이 나간다.
되는 일에 관리자 키를 끌어들이면 유출 시 피해 범위만 커진다.

대신 메일 문구가 "초대" 가 아니라 "로그인 링크" 계열이 된다.
링크를 누르면 세션이 만들어지고 `/invite/<token>` 수락 화면으로 이동한다.
문구가 중요하면 Supabase 의 Magic Link 템플릿을 손보면 된다
(`docs/email-templates/magic-link.html` 참고).

**이메일 일치를 요구한다.** 초대 링크가 유출돼도 다른 계정으로는 수락할 수 없다.

**발송이 실패해도 초대는 남는다.** UI 에 초대 링크가 노출되므로
슬랙 등으로 직접 전달할 수 있다.

## 제약

| 제약 | 내용 |
|---|---|
| 유효기간 | 14일 |
| 권한 | 초대는 `owner`/`admin` 만 가능 |
| 발송 한도 | Supabase Auth 기본 시간당 30통 (개인 Gmail 은 일 500통). 5인 팀엔 충분 |
| 동일 주소 재발송 | 60초 쿨다운 (사용자별) |
| 스팸함 | 개인 Gmail 발신이라 스팸으로 갈 수 있다. 초대할 때 미리 알려줄 것 |
