# 데이터베이스 (컬렉션)

노션의 "데이터베이스"에 해당한다. 표 / 보드 뷰로 같은 데이터를 다르게 본다.

## 쓰는 법

1. 사이드바 **새 페이지** → 빈 페이지에서 **데이터베이스로 만들기**
2. 기본 속성 3개(이름 / 태그 / 날짜)와 표 뷰 하나가 생긴다
3. **새 항목**으로 행 추가, 셀을 눌러 편집
4. 헤더의 **＋** 로 속성 추가, 헤더 이름을 누르면 정렬(오름 → 내림 → 해제)
5. **보드 추가** → 위쪽 **그룹** 에서 선택/상태 속성을 고르면 칸이 나뉜다

## 모델 — 행은 진짜 페이지다

```
pages (호스트)  ← collections.page_id
   └─ pages (행)   collection_id = 그 컬렉션, parent_id = 호스트
                   properties = { [propId]: value }
```

행이 페이지이므로 **행을 열면 그냥 문서**다(표에서 "열기"). 본문을 쓰고 하위 페이지도 만들 수 있다.

사이드바 트리에는 행이 안 나온다 — `getPageTree` 가 `collection_id IS NULL` 로 거른다.
안 그러면 100행짜리 표 하나가 사이드바를 덮는다.

## 속성 타입

| 지원 | 저장 형식 |
|---|---|
| 텍스트 / URL / 이메일 / 전화 | `"문자열"` |
| 숫자 | `42` |
| 체크박스 | `true` (거짓은 키를 지운다) |
| 선택 / 상태 | `"옵션명"` |
| 다중 선택 | `["a", "b"]` |
| 사람 | `["<userId>", ...]` |
| 날짜 | `{ "start": "2026-09-15" }` |
| 생성 일시 / 최종 편집 일시 / 만든 사람 / 최종 편집자 | 저장 안 함 — `pages` 컬럼에서 파생 |

**아직 없는 것:** 관계(relation) / 롤업 / 수식 / 파일.
`addProperty` 가 이 타입들을 아예 거부한다 — 반쯤 동작하는 컬럼을 만드는 것보다 낫다.

선택 계열은 셀에서 `＋ 새 옵션…` 으로 값을 만들면 **속성 스키마에도 자동 등록**된다.
이게 없으면 같은 태그를 행마다 다시 타이핑하게 되고, 보드 칸 순서도 잡히지 않는다.

## 필터·정렬은 메모리에서 한다

속성값이 jsonb 안에 있어 SQL 로 거르려면 타입별 캐스팅과 전용 인덱스가 필요하다.
5인 팀의 데이터베이스 하나는 많아야 수백 행이라, 전부 읽어와 JS 에서 거르는 편이
정확하고 단순하다. 상한은 **1,000행**이고 넘으면 화면에 알린다 — 그때가 SQL 로 내릴 신호다.

규칙은 `lib/collection-query.ts` **한 파일에만** 있고 서버와 클라이언트가 같이 쓴다.
갈라지면 "표에 보이는 값"과 "필터가 거른 값"이 달라진다.

## 셀 편집이 저장되는 시점

**포커스가 셀에서 빠질 때**(onBlur)다. 글자마다 저장하지 않는다 —
Next 16 은 서버 액션을 클라이언트당 **순차 디스패치**하므로, 타이핑마다 액션을 걸면
큐가 밀려 표가 눈에 띄게 느려진다.

같은 이유로 이 기능의 액션들은 `revalidatePath` 를 쓰지 않는다.
화면은 낙관적으로 먼저 바꾸고, 실패하면 되돌린다.

## 권한

컬렉션·뷰·속성 변경은 **호스트 페이지의 edit 권한**을 본다.
행의 변경은 그 행 페이지의 권한을 본다(`pages.ts` 가 이미 하던 것).
웹 UI 와 MCP 가 같은 `lib/core` 를 지나므로 경계가 갈라지지 않는다.

## 알아둘 제약

| 제약 | 내용 |
|---|---|
| 필터 UI | 데이터 모델(`view.config.filters`)과 서버 질의는 되어 있는데 **화면이 아직 없다**. 지금 만들 수 있는 건 정렬과 그룹뿐 |
| 캘린더 / 갤러리 / 목록 뷰 | `ViewType` 에는 있지만 아직 표·보드만 그린다 |
| 실시간 | 표는 Yjs 를 타지 않는다. 남이 고친 값은 새로고침해야 보인다 (본문 에디터는 실시간 그대로) |
| 행 순서 | 표에서 드래그로 재정렬하는 기능은 아직 없다. 정렬을 쓰거나 만든 순서대로 본다 |
| MCP | 데이터베이스 전용 툴은 아직 없다. `list_pages` 에는 행이 안 보인다(트리에서 제외되므로) |
